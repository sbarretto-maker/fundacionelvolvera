# Sitio web · Fundación El Volverá

Sitio estático bilingüe (español / inglés). No necesita servidor ni base de datos.

- `index.html`, `css/`, `js/`, `img/`: el diseño (no hace falta tocarlo para publicar contenido).
- `content/*.json`: todo el contenido editable (noticias, recursos, actividades, finanzas, datos de contacto y donaciones).
- `documentos/`: PDFs (estados auditados, informes), audios y folletos.
- `.pages.yml`: configuración del panel de administración (Pages CMS), que muestra formularios para editar `content/` y subir archivos sin programar.

Videos: súbalos a YouTube y pegue el enlace en el recurso; el sitio los muestra integrados.
